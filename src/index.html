    Conta e dados

    Os cafés ficam no banco de dados da Torra Local e aparecem em qualquer computador. Se este navegador já tinha cafés cadastrados antes, envie-os uma vez para o banco (os que já existem lá não são alterados).

    Cópia de segurança

    Os cafés e as configurações ficam guardados neste navegador, neste computador. Se os dados do navegador forem apagados, eles somem. Baixe uma cópia de vez em quando e guarde em local seguro.
